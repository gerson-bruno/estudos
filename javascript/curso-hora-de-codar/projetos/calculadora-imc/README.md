# 🧮 Calculadora de IMC

Uma calculadora de **IMC (Índice de Massa Corporal)** feita com **HTML, CSS e JavaScript puro**.  
O usuário informa **altura e peso**, e a aplicação calcula automaticamente o IMC e mostra a **classificação segundo a tabela padrão**.

## 🧠 Lógica aplicada

O cálculo segue a fórmula padrão:

```
IMC = peso / (altura × altura)
```

Depois do cálculo, o resultado é comparado com as faixas de classificação:

| IMC | Classificação |
|----|----|
| Menor que 18,5 | Magreza |
| 18,5 – 24,9 | Normal |
| 25 – 29,9 | Sobrepeso |
| 30 – 39,9 | Obesidade |
| 40+ | Obesidade grave |
