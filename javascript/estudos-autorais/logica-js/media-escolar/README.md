# Calculadora de Média Escolar

Aplicação desenvolvida para praticar manipulação de DOM, validação de dados e lógica condicional com JavaScript puro.

## 🎯 Objetivo

Permitir que o usuário insira três notas, calcular a média automaticamente e exibir o status final (Aprovado, Recuperação ou Reprovado) com feedback visual dinâmico.

## 🚀 Funcionalidades

* Entrada de três notas (0 a 10)
* Validação de campos vazios
* Validação de faixa permitida
* Cálculo automático da média
* Exibição da média com duas casas decimais
* Feedback visual com cores diferentes para cada resultado
* Limpeza automática dos campos após cálculo
* Foco automático no primeiro campo

## 🧠 Conceitos praticados

* Manipulação do DOM
* `addEventListener`
* Conversão explícita de tipo com `Number`
* Uso de `isNaN`
* Estrutura condicional (`if / else if / else`)
* Organização do fluxo com `return`
* Atualização dinâmica de conteúdo com `textContent`
* Alteração de estilo via JavaScript
* Uso de `toFixed()`

## 🛠 Tecnologias utilizadas

* HTML5
* CSS3 (Flexbox e efeitos visuais)
* JavaScript (Vanilla JS)

## 📈 Próximas melhorias possíveis

* Adicionar validação em tempo real
