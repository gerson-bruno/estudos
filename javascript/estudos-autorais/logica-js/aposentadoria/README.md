# Calculadora de Aposentadoria

Mini aplicação desenvolvida para praticar fundamentos de JavaScript aplicados ao front-end.

## 🎯 Objetivo

Implementar uma regra de negócio simples (verificação de elegibilidade para aposentadoria) com validação de dados e atualização dinâmica da interface.

## 🔎 Funcionalidades

* Entrada de idade via input numérico
* Validação de dados (campo vazio, valores inválidos)
* Regra condicional para elegibilidade (≥ 65 anos)
* Atualização dinâmica do conteúdo da página sem recarregar
* Manipulação de eventos com `addEventListener`

## 🧠 Conceitos aplicados

* Estruturação semântica com HTML5
* Layout centralizado com Flexbox
* Manipulação do DOM
* Conversão explícita de tipos (`Number`)
* Boas práticas com `textContent` (evitando `innerHTML` desnecessário)
* Organização básica de responsabilidades (estrutura, estilo e comportamento separados)

## 🛠 Tecnologias

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 📈 Evolução planejada

* Transformar em formulário com evento `submit`
* Feedback visual dinâmico (cores conforme resultado)
* Melhorar UX com validação em tempo real
* Refatorar para modularização da lógica
