# Projetos Autorais - HTML & CSS

Esta pasta reúne projetos desenvolvidos por mim utilizando HTML e CSS.

Diferente dos projetos de curso, aqui estão aplicações criadas de forma autoral, onde eu defini estrutura, layout e organização com base no que venho aprendendo.

---

## 📂 O que você vai encontrar aqui

Cada projeto está organizado em sua própria subpasta e contém:

- Código-fonte
- README individual
- Preview da interface

Os projetos variam entre:

- Landing pages
- Layouts institucionais
- Formulários
- Estruturas semânticas
- Experimentos de layout e organização visual

---

## ⭐ Destaque pessoal

Dentre os projetos dessa pasta, o que mais gostei de desenvolver foi o **projeto-azul**, um site sobre orcas.

Nesse projeto pude explorar melhor os conceitos de **Flexbox**, organizar seções com mais liberdade e trabalhar layout de forma mais consciente — além de desenvolver um tema que eu realmente gosto.

Foi um projeto onde consegui unir prática técnica com algo que me interessa de verdade.

Para visualizar o site, clique [aqui](https://gerson-bruno.github.io/estudos/html-css/estudos-autorais/projeto-azul/) 👈
