# 📝 Formulário Completo

Este é um **formulário completo (login, cadastro e recuperação de senha) moderno e responsivo**, desenvolvido para aprendizado. Ele inclui campos de entrada de dados, seleção de gênero e funcionalidades extras, como mostrar/esconder senha.  

---

## ✨ Funcionalidades

- **Campos de entrada:**
  - 👤 Nome
  - 📅 Data de nascimento
  - 📧 Email
  - 🔒 Senha
  - 🔑 Confirmar senha
- **Seleção de gênero:** 
  - 🚺 Feminino  
  - 🚹 Masculino  
  - ⚧ Outro
- **Ícones interativos:** 
  - 🖊️ Ícones à direita dos inputs
  - 👁️ Ícones de senha que alternam entre mostrar/esconder
  - 📆 Ícone de calendário ao lado do campo de data
- **Responsividade:** 📱💻 Funciona em desktops, tablets e smartphones
- **Estilo:** 
  - 🎨 Cores suaves e consistentes
  - ✨ Campos claros com sombras para destaque
  - 📝 Placeholder cinza antes do preenchimento
  - 📐 Layout centralizado e limpo

---

## 🛠️ Tecnologias

- 🌐 HTML5  
- 🎨 CSS3 (com Google Fonts)  
- ⚡ JavaScript para funcionalidades interativas  
- 🔗 Font Awesome para ícones
