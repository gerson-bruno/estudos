# Blog Semântico - HTML, CSS & JavaScript

Projeto de um blog desenvolvido com **HTML semântico**, **CSS básico** e **JavaScript** para alternância de tema (Dark Mode).

A proposta foi praticar:

- Estruturação correta com tags semânticas (`header`, `main`, `section`, `article`, `aside`, `footer`)
- Organização de layout
- Estilização com CSS
- Manipulação de DOM com JavaScript
- Implementação de **Dark Mode**
