Parágrafos e quebras de linhas.

Você pode escrever um parágrafo de qualquer jeito. Basta colocar tudo no meio do par de tags p e /p

Se precisar quebrar o texto em algum lugar específico como esse,
você pode usar a tag br.

Se você quiser que o < apareça na tela, você deve usar & lt; e se quiser que o > apareça, você deve usar o & gt; - ambos sem o espaço após o &.

Utilizando esse código você consegue mostrar os sinais de maior e menor
sem fazer com que o html use isso de forma errada como finalizar um parágrafo
por exemplo aqui: </p>

Existe a possíbilidade de adicionar um comentário que ficará invisível no site, com a função de deixar o seu código mais organizado. Para utilizar basta abrir o código com o sinal de maior !-- e defchar o código com -- e sinal de menor. Para ver o exemplo prático, acesse o HTML deste site.

Agora vamos adicionar simbolos especiais:
® para o símbolo de registrado
© para o símbolo de copyright
™ para o símbolo de marca registrada em inglês
No PDF que acompanha esta aula você encontra uma tabela com vários outros símbolos especiais que podem ser utilizados em HTML.

Emojis:

Para adicionar emojis, você pode usar o código Unicode do emoji. Por exemplo, para adicionar o emoji de coração, você pode usar o código 💓.
Aqui estão alguns exemplos de emojis:
Coração: 💓
Sorriso: 😀
Polegar para cima: 👍
Fogo: 🔥
Estrela: ⭐
Para conseguir esses códigos você pode acessar o site https://emojipedia.org/ e procurar o emoji desejado. Na página do emoji, você encontrará o Codepoints, que é o código necessário para adicioná-lo ao seu HTML.
Exemplo de emoji de natal no site do Emojipedia: 'U+1F385' que em HTML fica 🎅, para isso basta remover o U+ e adicionar o &# seguido do código numerico no emoji, para uma melhor organização você pode adicionar ';' após o código númerico.
