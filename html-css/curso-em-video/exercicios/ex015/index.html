Estilos CSS EXTERNOS

Este parágrafo está estilizado usando CSS EXTERNO. O estilo foi definido em um arquivo CSS separado.


Vantagens:

  • Manutenção facilitada: Alterações no estilo podem ser feitas em um único arquivo, afetando múltiplas páginas.
  • Reutilização de código: O mesmo arquivo CSS pode ser vinculado a várias páginas HTML.
  • Melhor organização: Separar o conteúdo (HTML) do estilo (CSS) torna o código mais limpo e fácil de entender.


Para mais informações sobre CSS EXTERNO, visite W3Schools - CSS How To.


É importante ressaltar que na mesma página é possível usar o CSS interno, externo e inline.

O Inline sobrepõe o CSS externo e interno, quando aplicado a um elemento específico.

O Interno substitui o externo, mas pode ser sobrescrito pelo inline.

O Externo é o estilo padrão aplicado a todas as páginas que utilizam o mesmo arquivo CSS.


É recomendado evitar de utilizar o CSS INLINE a menos que você queira fazer um ajuste muito específico.
Ja o CSS interno deve ser evitado pois deixa o código HTML mais complexo e difícil de manter.
