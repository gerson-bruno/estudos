Informações Adicionais

Usar CSS EXTERNO permite que você mantenha um design uniforme em todo o seu site, facilitando a atualização e a manutenção do estilo.

É importante manter o CSS em um arquivo separado para facilitar a manutenção e reutilização do código.

Vale lembrar que para adicionar o CSS EXTERNO, basta vincular o arquivo CSS ao HTML usando a tag link rel="stylesheet" href="nome_do_arquivo.css" no cabeçalho da página.
