Estilos CSS INTERNOS/LOCAL

Este parágrafo está estilizado usando CSS INTERNO/LOCAL. O estilo foi definido diretamente no documento HTML.


Utilidade:

Este método de estilização permite aplicar estilos específicos a um único documento HTML, sem a necessidade de criar arquivos CSS separados.


Desvantagens de utilizar o CSS INTERNO

  • Dificulta a manutenção do código, especialmente em projetos maiores.
  • Reduz a reutilização de estilos entre diferentes páginas.
  • Pode aumentar o tamanho do arquivo HTML, afetando o tempo de carregamento.

Sempre que o site possuir mais de uma página,
o CSS EXTERNO é preferível.
