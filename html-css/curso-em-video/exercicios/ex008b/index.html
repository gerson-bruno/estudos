Citações Simples:

Como diria o pai de um amigo:
O computador é um burro muito rápido.

Para realizar citações, utilize o comando Q.

O comando Q gera sentido as citações.

Então é preferencial que você use ele ao invés de usar somente as "aspas" no teclado.

Agora quando você precisar colocar apenas alguma coisa "entre aspas", sem que isso seja uma citação a alguém, é recomendado não usar o comando Q, utilizando as aspas do teclado.

Esse comando é diferente dos anteriores, apresentando uma diferença visível do método utilizado, como no exemplo abaixo:

Como diria o pai de um amigo:
O computador é um burro muito rápido. - Utilizando o comando Q.

Como diria o pai de um amigo:
"O computador é um burro muito rápido." - Utilizando as aspas do teclado.

As aspas geradas pelo comando Q não podem ser copiadas, quando o texto da citação é copiado.

O comando BLOCKQUOTE é usado para citar longos trechos de texto ou parágrafos. Fazendo com que esse texto citado tenha um recuo.
