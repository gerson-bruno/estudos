    O comando OL define uma lista ordenada.

    O comando UL define uma lista não ordenada.

    Ambos são comandos de listas.
    E para que os itens aparecam em lista é necessário a utilização da tag LI
    antes do item da lista. Esta tag não precisa de fechamento

Lista de definição

HTML
Linguagem de marcação para construção de páginas web.
CSS
Linguagem de estilo utilizada para estilizar páginas web.
JavaScript
Linguagem de programação utilizada para adicionar interatividade às páginas web.

Para uma lista de definição é necessário utilizar o comando DL, que define uma lista de definição.

Para adicionar o item na lista é necessário utilizar o comando DT
para definir o termo e DD para definir a descrição.
