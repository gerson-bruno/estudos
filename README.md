# Estudos

Este repositório reúne alguns dos **meus estudos pessoais em programação e tecnologia**.

Aqui estão projetos, exercícios, testes e exemplos que considerei relevantes para guardar, revisar e acompanhar minha evolução como desenvolvedor.

Não é um repositório focado em uma única linguagem ou stack.

---

## 📚 Sobre este repositório

A pasta **estudos** funciona como um **arquivo de aprendizado**.

Tudo que está aqui foi feito com objetivo de:
- praticar conceitos
- testar ideias
- reforçar fundamentos
- acompanhar evolução técnica ao longo do tempo

Os conteúdos não seguem um padrão único, porque refletem momentos diferentes do aprendizado.

---

## 🛠 Linguagens e tecnologias já utilizadas

Entre os estudos já presentes no repositório, estão:

- HTML
- CSS
- JavaScript
- Python

Outras linguagens e ferramentas podem aparecer conforme novos estudos forem sendo adicionados.

---

## 📁 Organização

Cada pasta representa uma **linguagem ou tecnologia** contendo subpastas com os respectivos estudos organizados por assunto.
